# IntelliJ IDEA Plugin Installation

## 1. Configure Proxy Settings

If your internet connection is working but you cannot access the **IntelliJ IDEA Marketplace**, you may need to configure the proxy settings.

Go to **Settings → Plugins**.

<p>
  <img width="784" height="327" alt="Plugin Settings" src="https://github.com/user-attachments/assets/a0327bc4-8e49-4a31-b5eb-a5a9303f22ea" />
</p>

Click **HTTP Proxy Settings**.

<p>
  <img width="646" height="183" alt="HTTP Proxy Settings" src="https://github.com/user-attachments/assets/35408576-12dd-444a-8b82-2698984686f5" />
</p>

Select **Auto-detect proxy settings**, then click **OK**.

<p>
  <img width="266" height="340" alt="Auto-detect Proxy Settings" src="https://github.com/user-attachments/assets/c21bfbe2-b905-4ac5-8216-c9172ab7e7a9" />
</p>

You should now be able to access the **IntelliJ IDEA Marketplace**.

<p>
  <img width="679" height="511" alt="IntelliJ IDEA Marketplace" src="https://github.com/user-attachments/assets/13006118-4c0e-49c8-8709-d554dd88fc5a" />
</p>
