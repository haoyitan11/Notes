# 4.3 列表 (List)

列表（list）是一个抽象的数据结构概念，它表示元素的有序集合，支持元素访问、修改、添加、删除和遍历等操作，无须使用者考虑容量限制的问题。列表可以基于链表或数组实现。

链表天然可以看作一个列表，其支持元素增删查改操作，并且可以灵活动态扩容。
数组也支持元素增删查改，但由于其长度不可变，因此只能看作一个具有长度限制的列表。
当使用数组实现列表时，长度不可变的性质会导致列表的实用性降低。这是因为我们通常无法事先确定需要存储多少数据，从而难以选择合适的列表长度。若长度过小，则很可能无法满足使用需求；若长度过大，则会造成内存空间浪费。

为解决此问题，我们可以使用动态数组（dynamic array）来实现列表。它继承了数组的各项优点，并且可以在程序运行过程中进行动态扩容。

实际上，许多编程语言中的标准库提供的列表是基于动态数组实现的，例如 Python 中的 list 、Java 中的 ArrayList 、C++ 中的 vector 和 C# 中的 List 等。在接下来的讨论中，我们将把“列表”和“动态数组”视为等同的概念。

A "list" is an abstract data structure concept representing an ordered collection of elements. It supports operations such as accessing, modifying, adding, removing, and iterating over elements, without requiring the user to worry about capacity constraints. Lists can be implemented using either linked lists or arrays.

A linked list can naturally be viewed as a list; it supports element insertion, deletion, retrieval, and modification, and allows for flexible, dynamic expansion.
Arrays also support these operations, but because their length is fixed, they can only be considered length-constrained lists.
When an array is used to implement a list, its fixed-length nature limits practicality. This is because we often cannot determine the amount of data to be stored in advance, making it difficult to choose an appropriate length. If the length is too small, it may fail to meet requirements; if it is too large, memory space is wasted.

To address this issue, we can implement a list using a dynamic array. This structure retains the advantages of a standard array while allowing for dynamic expansion during program execution.

In fact, the list implementations found in the standard libraries of many programming languages—such as Python's `list`, Java's `ArrayList`, C++'s `vector`, and C#'s `List`—are based on dynamic arrays. In the following discussion, we will treat "list" and "dynamic array" as equivalent concepts.

## 4.3.1   列表常用操作 (Common List Operations)
### 1.   初始化列表 (Initialization list)
我们通常使用“无初始值”和“有初始值”这两种初始化方法：

We typically use two initialization methods: "without an initial value" and "with an initial value."

```java
/* 初始化列表 */
// 无初始值
List<Integer> nums1 = new ArrayList<>();
// 有初始值（注意数组的元素类型需为 int[] 的包装类 Integer[]）
Integer[] numbers = new Integer[] { 1, 3, 2, 5, 4 };
List<Integer> nums = new ArrayList<>(Arrays.asList(numbers));
```

### 2.   访问元素 (Access elements)
列表本质上是数组，因此可以在O(1)时间内访问和更新元素，效率很高。

Lists are essentially arrays; therefore, elements can be accessed and updated in O(1) time, making them highly efficient.

### 3.   插入与删除元素 (Inserting and deleting elements)
相较于数组，列表可以自由地添加与删除元素。在列表尾部添加元素的时间复杂度为 O(1)，但插入和删除元素的效率仍与数组相同，时间复杂度为 O(N)。

Unlike arrays, lists allow for the dynamic addition and removal of elements. While adding an element to the end of a list has a time complexity of O(1), the efficiency of inserting or deleting elements remains the same as that of arrays, with a time complexity of O(N).

```java
/* 清空列表 */
nums.clear();

/* 在尾部添加元素 */
nums.add(1);
nums.add(3);
nums.add(2);
nums.add(5);
nums.add(4);

/* 在中间插入元素 */
nums.add(3, 6);  // 在索引 3 处插入数字 6

/* 删除元素 */
nums.remove(3);  // 删除索引 3 处的元素
```

### 4.   遍历列表 (Traverse a List)
与数组一样，列表可以根据索引遍历，也可以直接遍历各元素。

Like arrays, lists can be traversed by index or by directly iterating through elements.

```java
/* 通过索引遍历列表 */
int count = 0;
for (int i = 0; i < nums.size(); i++) {
    count += nums.get(i);
}

/* 直接遍历列表元素 */
for (int num : nums) {
    count += num;
}
```

### 5.   拼接列表 (Concatenate lists)
给定一个新列表 nums1 ，我们可以将其拼接到原列表的尾部。

Given a new list nums1, we can concatenate it to the end of the original list.

```java
/* 拼接两个列表 */
List<Integer> nums1 = new ArrayList<>(Arrays.asList(new Integer[] { 6, 8, 7, 10, 9 }));
nums.addAll(nums1);  // 将列表 nums1 拼接到 nums 之后
```

### 6.   排序列表 (Sort a List)
完成列表排序后，我们便可以使用在数组类算法题中经常考查的“二分查找”和“双指针”算法。

After sorting a list, we can use "binary search" and "two-pointer" algorithms, which are frequently tested in array algorithm problems.

```java
/* 排序列表 */
Collections.sort(nums);  // 排序后，列表元素从小到大排列
```
