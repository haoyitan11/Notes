# 4.2   链表 (Linked list)

内存空间是所有程序的公共资源，在一个复杂的系统运行环境下，空闲的内存空间可能散落在内存各处。我们知道，存储数组的内存空间必须是连续的，而当数组非常大时，内存可能无法提供如此大的连续空间。此时链表的灵活性优势就体现出来了。

链表（linked list）是一种线性数据结构，其中的每个元素都是一个节点对象，各个节点通过“引用”相连接。引用记录了下一个节点的内存地址，通过它可以从当前节点访问到下一个节点。

链表的设计使得各个节点可以分散存储在内存各处，它们的内存地址无须连续。

Memory space is a shared resource for all programs; in a complex system environment, available memory may be scattered across various locations. We know that the memory space used to store an array must be contiguous, yet when an array is very large, the system may be unable to provide such a large, unbroken block of memory. This is where the flexibility of a linked list proves advantageous.

A linked list is a linear data structure in which each element is a node object, and the nodes are connected via "references." A reference stores the memory address of the next node, enabling access to the next node from the current one.

The design of a linked list allows individual nodes to be stored at scattered locations throughout memory; their memory addresses do not need to be contiguous.

As shown in Figure 4-5, the building blocks of a linked list are node objects. Each node contains two pieces of data: the node's "value" and a "reference" pointing to the next node.
- The first node of the linked list is called the "head node," and the last node is called the "tail node."
- The tail node points to "null" (or an equivalent empty value), denoted as `null` in Java, `nullptr` in C++, and `None` in Python.
- In languages ​​that support pointers—such as C, C++, Go, and Rust—the aforementioned "reference" should be replaced with a "pointer."
As illustrated in the code below, a linked list node (`ListNode`) must store an additional reference (or pointer) alongside its value. Consequently, for the same amount of data, a linked list consumes more memory than an array.

```java
/* 链表节点类 */
class ListNode {
    int val;        // 节点值
    ListNode next;  // 指向下一节点的引用
    ListNode(int x) { val = x; }  // 构造函数
}
```
