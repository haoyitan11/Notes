# 4.4 内存与缓存 (Random-Access Memory and Cache)
在本章的前两节中，我们探讨了数组和链表这两种基础且重要的数据结构，它们分别代表了“连续存储”和“分散存储”两种物理结构。

实际上，物理结构在很大程度上决定了程序对内存和缓存的使用效率，进而影响算法程序的整体性能。

In the first two sections of this chapter, we explored arrays and linked lists, two fundamental and important data structures that represent two physical layouts: "contiguous storage" and "distributed storage", respectively.

In fact, physical structure largely determines the efficiency with which programs utilize memory and cache, which in turn affects the overall performance of algorithmic programs.

## 4.4.1   计算机存储设备 (Computer Storage Devices)
计算机中包括三种类型的存储设备：硬盘（hard disk）、内存（random-access memory, RAM）、缓存（cache memory）。表 4-2 展示了它们在计算机系统中的不同角色和性能特点。

Computers include three types of storage devices: hard disk, random-access memory (RAM), and cache memory. The following table shows their different roles and performance characteristics in a computer system.


|                      | 硬盘 (Disk Storage) | 内存 (Memory / RAM) | 缓存 (Cache) |
|----------------------|---------------------|---------------------|--------------|
| **用途 (Purpose)** | 长期存储数据，包括操作系统、程序、文件等 (Long-term storage of data, operating systems, applications, and files) | 临时存储当前运行的程序和正在处理的数据 (Temporarily stores running programs and active data) | 存储经常访问的数据和指令，减少 CPU 访问内存的次数 (Stores frequently accessed data and instructions to reduce CPU memory access) |
| **易失性 (Volatility)** | 断电后数据不会丢失 (Data persists after power loss) | 断电后数据会丢失 (Data is lost after power loss) | 断电后数据会丢失 (Data is lost after power loss) |
| **容量 (Capacity)** | 较大，TB 级别 (Large, typically TB scale) | 较小，GB 级别 (Smaller, typically GB scale) | 非常小，MB 级别 (Very small, typically MB scale) |
| **速度 (Speed)** | 较慢，几百到几千 MB/s (Relatively slow, hundreds to thousands of MB/s) | 较快，几十 GB/s (Fast, tens of GB/s) | 非常快，几十到几百 GB/s (Very fast, tens to hundreds of GB/s) |
| **价格 (Cost)** | 较便宜，几毛到几元 / GB (Relatively inexpensive, cents to a few RMB per GB) | 较贵，几十到几百元 / GB (More expensive, tens to hundreds of RMB per GB) | 非常贵，通常随 CPU 一同计价 (Very expensive, generally bundled with the CPU) |
